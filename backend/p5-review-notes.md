# 小五复习区

12套×15题，受保护资源ID `p5-review`，沿用 `p6-standard` 授权。完整题目与答案只发布到现有私有课程内容及目录，不放在匿名网站资源中。

- `p5-review-schema.sql`：新增私有 `p5_retries` 表、限定身份的RPC、首次成绩分析；原表不改写。
- `p5-review-first-stats.sql`：只对新资源增加首次提交筛选，其他资源口径保持原样。
- `p5-review-ui.js`：完整交卷、服务器保存确认、首次错题自主重做。
- `p5-review-rollback.sql`：停用新接口及入口授权，保留全部成绩；同时恢复前端及reports Edge Function前一版本。
- 题库维护：稳定题号与答案目录须一致更新；有学生作答后不改变原题号含义，新增版本使用新题号。

教师从现有功课管理选择小学普通华文，再选择“小五复习区”套数。一键和批量布置均可使用。教师月报内新增小五统计，可切换所选月份和累计至月末，导出独立CSV；原PDF版面保持不变。

首次统计按全历史最早有效完整提交确定后才归月（Asia/Singapore），局部重做不会进入learning_runs，也不会标记作业完成。样本阈值集中在p5-analysis.js：至少5题，80%掌握，60%巩固，低于60%优先强化。跨月比较只比较两个月的首次题目且各至少5题。

验证：本地隔离数据库验证180题批改、授权、首次/后续/重做隔离、重复提交、月界、功课开放截止及结束；页面模拟验证保存确认、失败重试、隐藏答案、错题子集和七类统计；既有登录导航、功课及批量安排回归通过。未使用真实学生作业测试。手机390px及电脑页面检查通过；未声称完成真实iPhone Safari设备测试。
