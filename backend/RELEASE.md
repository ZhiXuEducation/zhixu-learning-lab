## 本版内容

- 学生编号 + 随机四位 PIN 登录；管理员仍使用现有邮箱与密码。
- 新增、列出、修改、停用学生，以及重设 PIN。
- 年级限 P6、S1–S4，对应当前已有课程；中学生可另授作文审题。
- 创建或重设时仅返回一次 PIN，页面不写入浏览器存储；管理员可隐藏显示。
- PIN 使用服务端密钥 HMAC 预处理、随机盐、PBKDF2-SHA256（210,000 次）后存储。
- 固定服务端限流：每个编号每15分钟最多5次尝试，每24小时最多10次；成功登录清除该账号计数。全站每15分钟100次，限制未知编号探测。管理员重设 PIN 可清除账号计数。
- 学生会话为随机256位令牌；数据库只保存令牌哈希，8小时到期。浏览器在当前标签页 sessionStorage 保存会话令牌，不保存 PIN。
- 停用、编辑、重设 PIN 会撤销该学生的现有会话；每次课程请求再次检查启用状态及授权。
- 学生会话只对专用课程接口有效，不赋予直接访问 Supabase 数据接口的身份。
- 业务表通过 RLS 限管理员读取；凭据、会话、限流、课程正文置于 zx_private，前端无权读取。
- 原有表、记录、管理员角色、RLS 策略不覆盖。暂不做报告、成绩统计或教师管理。

## 课程保护与既有公开内容

13份练习页面及其脚本已在本地打包为私有课程正文。发布时把它们存入私有数据表；原网址保留为登录跳转，移除公开网站中的题目脚本副本。课程接口只返回当前学生获授权的正文。小学 PSLE 冲刺供已获授权的两种小六课程使用；原20题复习供已获任一现有课程的学生使用。

**这些材料此前已出现在公开 GitHub 仓库。此方案保护新网站的课程接口，不能阻止别人从公开仓库历史、旧部署或已有副本取得旧材料。** 若要求材料保密，需要另行决定代码仓库、历史、旧部署与托管方式；本次不擅自改仓库可见性或删除历史。

已加载到学生浏览器的课程正文无法远程收回；停用会阻止后续服务端请求。
